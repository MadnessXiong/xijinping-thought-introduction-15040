## 学习与答题

1. 从[按章讲义](学习方案.html)选择导论或第1—17章，先闭书复述概念，再看关系、例子和易错点。讲义中的题库跳转会打开对应自编题。
2. 在[答题网页](practice.html)按教材章节、题型或知识模块分类；可叠加搜索、考期／自编来源、错题与未答筛选。单选按唯一答案、多选按完整集合自动判分；填空只匹配可靠别名。简答、论述、材料题由使用者对照参考要点人工自评，人工评价不计入自动正确率。疑题不计分。
3. 在[大题训练页](大题冲刺_20261018.html)先做16道“优先”题，再补其余12题；每题先写草稿，再展开自编参考要点。四期C类主题只作练习线索，不能得出真实高频、必考或命中概率。[28题JSON](大题重点训练_28题.json)与[复核记录](reports/大题冲刺第二批补充与复核_20261018.md)可单独查看。
4. [真题索引](docs/真题索引与逐考期缺口.html)逐考期说明所能访问的来源、完整程度、缺失和下载结果。“未找到”不等于该考期未开考；商品目录、搜索摘要和视频标题不当作已取得试卷。

答题页将草稿、答题记录、错题和分类选择保存在**当前浏览器的 localStorage**。GitHub Pages网址与本地文件、其他浏览器或设备属于不同存储位置，进度不会自动同步。迁移前在答题页“导出进度”，打开新位置后用“导入备份”；不要在公共设备保存个人作答。大题训练草稿使用独立存储键，不进入主库的自动正确率，也不自动并入主库备份。
