考前速记：先认问法，再组织答案

  1. “是什么”：给出规范概念或完整列项；根本、基础、宗旨、总目标、总抓手不可换词。
  2. “为什么”：从地位、作用、现实需要等层次说明意义，不只写具体做法。
  3. “怎样做”：写原则与路径，并对应题目条件；避免只有意义没有措施。
  4. “关系”：分别界定两端，再写相互联系与作用；不是各背一段就结束。
  5. “材料分析”：材料中的事实→相应理论→如何体现→答题结论；每点都应有材料依据。
  6. “不正确／不属于”：先标记否定词，选项判断完成后再回到题目确认；多选练习须核对完整集合。

六个必须坚持：人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下。

中国式现代化五个中国特色：人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路。

中华文明五个突出特性：连续性、创新性、统一性、包容性、和平性。
